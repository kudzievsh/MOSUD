# Практическая работа № 3

**Тема:** Выборка, проекция, переименование и реляционная алгебра  
**Вариант:** 3

## Задание варианта

Исходное отношение — `olist.products`.

Предикат:

```text
1000 <= weight_g <= 5000 AND photos_qty >= 3
```

Проекция:

```text
product_id, category, weight_g, photos_qty
```

В базе Olist этим обозначениям соответствуют поля:

- `product_category_name` → `category`;
- `product_weight_g` → `weight_g`;
- `product_photos_qty` → `photos_qty`.

## Реляционное выражение

Основное выражение:

```text
π_{product_id, product_category_name, product_weight_g, product_photos_qty}
(
  σ_{1000 <= product_weight_g <= 5000 ∧ product_photos_qty >= 3}
  (products)
)
```

С явным переименованием атрибутов результата:

```text
ρ_{category ← product_category_name,
  weight_g ← product_weight_g,
  photos_qty ← product_photos_qty}
(
  π_{product_id, product_category_name, product_weight_g, product_photos_qty}
  (
    σ_{1000 <= product_weight_g <= 5000 ∧ product_photos_qty >= 3}
    (products)
  )
)
```

Эквивалентная запись с двумя последовательными выборками:

```text
π_{product_id, product_category_name, product_weight_g, product_photos_qty}
(
  σ_{product_photos_qty >= 3}
  (
    σ_{1000 <= product_weight_g <= 5000}(products)
  )
)
```

## Результаты выполнения

|---|---:|

| Строк в итоговой выборке | 2 628 |
| Несовпадений: исходный запрос ↔ две последовательные выборки | 0 |
| Несовпадений: исходный запрос ↔ вариант с ранней проекцией | 0 |
| Строк после `SELECT DISTINCT` заданной проекции | 2 628 |
| Избыточных дубликатов в заданной проекции | 0 |
| Строк в дополнительной проекции без `product_id` | 2 628 |
| Уникальных строк в дополнительной проекции без `product_id` | 1 851 |
| Избыточных дубликатов без `product_id` | 777 |

## Вывод

Разбиение исходного сложного предиката на две последовательные выборки не изменило результат: сравнение через `EXCEPT` в обе стороны дало `0` несовпадений. Вариант с ранней проекцией также эквивалентен исходному запросу, поскольку до фильтрации сохраняются все атрибуты, необходимые для условия и результата. В заданной проекции присутствует `product_id`, являющийся ключом товара, поэтому `SELECT` и `SELECT DISTINCT` возвращают одинаковые 2 628 строк и полных дубликатов нет. Если исключить `product_id` из проекции, разные товары могут иметь одинаковые значения категории, веса и количества фотографий: в данном наборе данных получено 1 851 уникальное сочетание из 2 628 строк, то есть 777 избыточных повторений. Это показывает отличие математической проекции, устраняющей повторяющиеся кортежи, от обычного `SELECT` в SQL.
